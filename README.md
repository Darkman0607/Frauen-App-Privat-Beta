# Frauen-App Beta 0.1.9.0 (Kalender Redesign mit Icons)

Update von 0.1.8.9 auf 0.1.9.0 (Build 14):
- **Komplettes Redesign des Kalenders (`calendar()`):**
  - Statt bloßer Punkt-Punkte (`● 1`) zeigt jeder Tag jetzt direkt die **passenden bunten Themen-Icons** der eingetragenen Beobachtungen:
    - 🩸 Periode / Zwischenblutung
    - 🤒 Krankheit / Symptome
    - 💧 Ausfluss
    - ✨ Zervixschleim / Eisprung
    - 🔦 Gemeinsame Selbstkontrolle / Spekulum / VU
    - 🩺 Frauenarzttermin / Labor
  - **Farbliche Tageskarten:**
    - Tage mit Periode färben sich sanft rosé-rötlich ein.
    - Tage mit Krankheit färben sich sanft warm-orange ein.
    - Der heute aktuelle Tag hat eine markante pinke Kontur.
    - Der angetippte/ausgewählte Tag hebt sich mit einem samtigen Beeren-Farbverlauf und weißer Schrift ab.
  - **Zähler-Pill oben rechts:** Zeigt die genaue Anzahl der Einträge pro Tag an.
  - **Neuer Monatswechsler & Schnellbutton:**
    - Monatsleiste mit Pfeilen (`◀` / `▶`) und großem Monatsnamen.
    - Schnellbutton **„＋ Eintrag am DD.MM.“**, um direkt für den ausgewählten Tag ein Ereignis zu erfassen.
    - Praktische Legende am Fuß des Kalenders.
