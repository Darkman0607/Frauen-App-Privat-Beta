# Frauen-App Beta 0.1.7.2

Update von 0.1.7.1:
- Erweiterung des Lernzentrums um 4 neue Fachlektionen aus Hebammen- und gynäkologischer Praxis:
  1. Muttermundtastung nach NFP / Sensiplan (Höhe, Festigkeit, Öffnung)
  2. Lutealphase und Brustveränderungen (Gelbkörperfunktion / Mastodynie)
  3. Beckenboden im Alltag und Zyklus (Wahrnehmung & Tonus)
  4. Wochenbett: Lochien (Wochenfluss) und Uterusrückbildung
- Dynamischer Zähler und Lernfortschritt im Lernzentrum (jetzt 14 vertiefte Fachlektionen).
- PWA-Cache und Assets auf Build 172 aktualisiert (automatischer Cache-Refresh).
- Verschlüsselte IndexedDB-Struktur, Tagebucheinträge und Fotos bleiben unverändert erhalten.

## Installation
Alle enthaltenen Dateien im GitHub-Repository-Hauptverzeichnis ersetzen bzw. ergänzen und commiten. Kein Browser-Cache-Löschen nötig. Vor Updates empfiehlt sich wie immer ein Export-Backup.
